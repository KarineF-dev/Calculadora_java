   ■ Calculadora em Java

Projeto simples de calculadora desenvolvido em Java com foco em prática de lógica de programação.



● Funcionalidades
- Soma
- Subtração
- Multiplicação
- Divisão
- Menu interativo no console



● Tecnologias utilizadas
- Java



● Objetivo
Este projeto foi desenvolvido para praticar:
- Estruturas condicionais
- Entrada e saída de dados
- Lógica de programação
